# Gate: SEO

> A public website can be found and read by search engines.

## Checks

- Technical: titles, descriptions, canonical URLs, sitemap, robots, status codes and speed.
- Content: one clear heading structure and text that answers the page's purpose.
- Structured data valid for the page type.
- Rules: SEO-01, SEO-02, SEO-03, SEO-04, SEO-05, SEO-06, SEO-07. Run `{{ABMH}}checks/check.sh seo`; they exist only where the optional web pack is installed. A FAIL blocks, a NOT RUN is reported.

## Who

- The Diseñador (`{{ABMH}}agents/designer.md`).

## Applies when

- A public website is about to be published or its public pages change. Not for apps behind a login.

## Evidence

- The checks run, what failed and what was fixed, before publishing.

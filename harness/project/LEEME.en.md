# README

Audience: both

> **Summary:** entry point to the project's docs folder. It says what is here and in what order to read it.
> Kept by whoever works on the project; files link to each other with `[[name]]`.
> Last reviewed: YYYY-MM-DD

## What is here

- `STATUS.md`: where the project stands now and what is blocked.
- `MEMORY.md`: what was learned and should not be forgotten. Pruned; 8 KB cap.
- `GAPS.md`: what we do not know yet. Add a line instead of assuming.
- `GLOSSARY.md`: the project's words and their single meaning.
- `ROTATION.md`: what to do when a secret leaks: which secrets exist and the steps to replace them.
- `decisions/`: each important decision with its reason.

## How to use it

1. Read `STATUS.md`, then `MEMORY.md`.
2. Before proposing something big, check `decisions/` and `GAPS.md`.
3. Every new file starts with `Audience: person | agent | both` and a 3-line summary.

# Decisiones

Audience: both

> **Resumen:** por qué se hizo cada cosa importante, una decisión por archivo.
> Se escribe cuando se decide algo difícil de revertir; no se borra, solo se sustituye.
> Última revisión: AAAA-MM-DD

Aquí se guarda **por qué** se hizo cada cosa importante, para que ni tú ni el asistente tengáis que adivinarlo después.

## Cómo se usa

1. Cuando se tome una decisión que cueste cambiar (tecnología, estructura, un criterio de negocio), copia `TEMPLATE.md` a `ADR-001-titulo-corto.md` (el número sube con cada decisión).
2. Rellénalo en pocas líneas: contexto, decisión, alternativas descartadas y consecuencias.
3. Una decisión por archivo. No se borran: si cambia, se escribe otra y la antigua se marca como sustituida.

## Para el asistente

Antes de proponer algo grande, lee esta carpeta. Cuando se decida algo, deja el ADR aquí. La plantilla completa está en `.abmh/core/templates/ADR.template.md`.

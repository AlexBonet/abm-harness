# grill

Use it only when {{OWNER}} asks for it by name.

Read `{{CORE}}protocols/GRILL.md` and follow it. Chat in the language of the project; anything written to files in English.

- Ask by rounds, each question with a recommended answer worded so "yes" accepts it.
- Facts are yours to look up; ask only for decisions.
- When the frontier is empty and {{OWNER}} confirmed, propose glossary terms and decision records, and write only the items {{OWNER}} accepts, one by one.

Source: ideas from Matt Pocock's `grilling` and `grill-with-docs` skills (MIT licence); nothing is copied.
